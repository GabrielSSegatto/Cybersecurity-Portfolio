# Internal Security & Compliance Audit

## Project Overview
This project simulates an internal security audit for a fictional company (Botium Toys). The goal was to assess the current security posture, identify vulnerabilities in asset management, and ensure compliance with international regulations and frameworks.

##  Objectives
* Conduct a risk assessment based on the **NIST Cybersecurity Framework (CSF)**.
* Evaluate the implementation of administrative, technical, and physical controls.
* Verify compliance readiness for **PCI-DSS**, **GDPR**, and **SOC (Type 1 & 2)**.

## Tools & Frameworks Used
* **NIST CSF** (Identify, Protect, Detect, Respond, Recover)
* **Compliance Standards:** GDPR, PCI-DSS, SOC
* Risk Assessment & Gap Analysis

## Key Findings & Recommendations
During the audit, several critical gaps were identified, such as the lack of an Intrusion Detection System (IDS), inadequate password management, and non-compliance with the Principle of Least Privilege. 

To mitigate these risks, a 5-step action plan was recommended to stakeholders:
1. Deploy Data Encryption (at rest and in transit).
2. Implement Identity and Access Management (IAM) with Least Privilege.
3. Adopt a centralized Password Management System with MFA.
4. Establish a routine for Backups and a Disaster Recovery Plan (DRP).
5. Install an Intrusion Detection System (IDS).
